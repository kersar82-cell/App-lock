# FocusLock — টাইমার-ভিত্তিক অটো ফোন লক অ্যাপ

## এই অ্যাপ কী করে
- একটা টাইমার (মিনিট) সেট করবেন — সময় শেষ হলে **DevicePolicyManager.lockNow()** দিয়ে ফোন সরাসরি লক হয়ে যাবে।
- একটা লিস্ট থেকে যেকোনো অ্যাপ সিলেক্ট করতে পারবেন — টাইমার চলাকালীন ওই অ্যাপগুলো খোলার সাথে সাথে হোম স্ক্রিনে ফিরিয়ে দেওয়া হবে (কার্যকরভাবে "বন্ধ" রাখা)।
- অ্যাপের নিজস্ব PIN ছাড়া টাইমার/ব্লকিং বন্ধ করা যাবে না।
- Device Admin অ্যাক্টিভ থাকলে অ্যাপটা আনইনস্টল করার আগে সিস্টেম নিজেই একটা এক্সট্রা "Deactivate admin" ধাপ চাপিয়ে দেয়।

## যা সম্ভব না (সততার সাথে বলা দরকার)
- সাধারণ (non-root, non-Device-Owner) অ্যাপ অন্য অ্যাপকে সরাসরি "Force Stop" করতে পারে না — এটা Android নিরাপত্তার কারণে নিষিদ্ধ করে রেখেছে (Android 5.0+ থেকে)। তাই এই অ্যাপ Accessibility Service দিয়ে "ব্লকলিস্টের অ্যাপ খুললেই হোমে ফেরত পাঠানো" পদ্ধতি ব্যবহার করে — ইউজার এক্সপেরিয়েন্সে একই ফল পাওয়া যায়।
- আনইনস্টল ১০০% আটকানো সম্ভব শুধু "Device Owner" মোডে (এন্টারপ্রাইজ ফোন ম্যানেজমেন্টে ব্যবহৃত হয়, ADB দিয়ে বিশেষভাবে প্রোভিশন করতে হয়, সাধারণত ফ্যাক্টরি রিসেটের পর)। এই প্রজেক্টে সেটা নেই — Device Admin দিয়ে শুধু "কঠিন করা" হয়েছে।

## কীভাবে চালাবেন
1. [Android Studio](https://developer.android.com/studio) ইনস্টল করুন।
2. এই `FocusLock` ফোল্ডারটা **Open an existing project** দিয়ে খুলুন। Gradle সিঙ্ক হতে দিন (প্রথমবার ইন্টারনেট লাগবে — Gradle wrapper ও লাইব্রেরি ডাউনলোড হবে)।
3. একটা ফোন/এমুলেটর কানেক্ট করে **Run ▶️** চাপুন।
4. অ্যাপ খুলে এই ক্রমে সেটআপ করুন:
   - **PIN সেট করুন**
   - **Device Admin চালু করুন**
   - **Accessibility চালু করুন** (Settings-এ গিয়ে "FocusLock" খুঁজে চালু করতে হবে)
   - **ব্যাটারি অপ্টিমাইজেশন বন্ধ করুন** (যাতে টাইমার মাঝপথে সিস্টেম বন্ধ করে না দেয়)
5. মিনিট লিখুন, ব্লক করার অ্যাপগুলো টিক দিন, **শুরু করুন** চাপুন।
6. টাইমার শেষ হলে ফোন অটো লক হয়ে যাবে। মাঝপথে বন্ধ করতে হলে **বন্ধ করুন (PIN)** বাটনে PIN দিতে হবে।

## গুরুত্বপূর্ণ নোট
- এটা `minSdk 26` (Android 8.0+) টার্গেট করে লেখা।
- প্রথমবার Gradle sync করতে ইন্টারনেট লাগবে (dependencies ডাউনলোডের জন্য), এরপর অফলাইনেও অ্যাপ কাজ করবে।
- নিজের PIN ভুলে গেলে সেটিংস থেকে অ্যাপ ডেটা ক্লিয়ার করতে হবে (Settings > Apps > FocusLock > Storage > Clear Data), তারপর নতুন করে PIN সেট করতে হবে।
